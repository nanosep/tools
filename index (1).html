What it is: Turning rambling drafts into 3‑sentence executive summaries that pass the “hallway test”.
When to use: For status updates, proposals, and memos to senior leaders where clarity and brevity are critical.

STEP 1 — Extract Core Signal (Before writing):
First, analyze the raw input and identify:
- What decision is actually on the table? (Be specific: "Approve $2.3M budget" not "invest in growth")
- What's the forcing function? (Why can't this wait 90 days?)
- What's at risk? (Quantify if possible: "$4M revenue opportunity" not "competitive risk")

Write these 3 elements as bullets. If any are unclear from the input, flag it.

STEP 2 — Draft 3-Sentence Summary:
- Sentence 1: [SITUATION + TENSION] — What's the current state and why it's unsustainable
- Sentence 2: [RECOMMENDATION + PRIMARY BENEFIT] — What you propose and the measurable upside
- Sentence 3: [COST OF INACTION] — What we lose (revenue, time, position) if we delay

STEP 3 — Quality Check (Self-critique):
Run each sentence through these filters:
✓ No weak verbs (avoid: leverage, utilize, implement, drive, enable)
✓ No hedging (avoid: might, could, potentially, possibly, consider)
✓ No jargon (avoid: ecosystem, synergy, paradigm, holistic)
✓ Concrete > Abstract (say "$2M" not "significant revenue")
✓ Active voice (say "Launch X" not "X should be launched")

List any violations you found, then revise.

STEP 4 — Alternative Framings:
Generate 2 alternative versions optimized for different audiences:
- VERSION A (Risk-averse CFO): Lead with financial downside
- VERSION B (Growth-focused CEO): Lead with competitive positioning

STEP 5 — Final Check:
- Read your main summary aloud in 10 seconds. Did you naturally emphasize the decision?
- If someone interrupted you after sentence 2, would they know enough to say yes/no?
- Flag any sentence that requires context from the original doc to understand

OUTPUT:
- Main 3-sentence summary
- Version A (CFO-optimized)
- Version B (CEO-optimized)
- Self-critique notes
- Confidence rating (High/Medium/Low) on whether this passes the hallway test
